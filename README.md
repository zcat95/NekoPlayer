# Neko Player

一个刷本地短视频的小播放器。

选好几个文件夹就能上下滑着看，支持随机播放、未看优先、收藏、长按倍速和后台播放。

需要 Android 12 及以上。界面用 [Miuix](https://github.com/compose-miuix-ui/miuix)，玻璃效果用 [Backdrop](https://github.com/Kyant0/AndroidLiquidGlass)。

## 2.6.0-beta.1

- 多个目录合并播放，可以单独启停。
- 双击点赞，调整了播放缓冲和预览占用。
- 手机上可以记录诊断、复制摘要或导出报告。
