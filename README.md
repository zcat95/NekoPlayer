# Neko Player

一个刷本地短视频的小播放器。

选好文件夹就能上下滑着看，支持随机播放、未看优先、收藏、长按倍速和后台播放。

需要 Android 12 及以上。界面用 [Miuix](https://github.com/compose-miuix-ui/miuix)，玻璃效果用 [Backdrop](https://github.com/Kyant0/AndroidLiquidGlass)。

## 2.5.1

- 优化视频切换和预载。
- 加了未看优先开关、缓存查看和清理。
- 长按加速会轻震，滑动时取消加速。
